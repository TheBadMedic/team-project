User Story:
User story 1: As a user, I want to check the weather conditions around me by being
able to zoom in/out on the map, or pan around the map to look at a specific location.(JunXi Huang)
User story 2: As a user, I want an information panel to pop up when I zoom in close
enough to a specific city (or landmark). I want the panel to display information about
the weather at the location, temperature, and-or other data like forecasted weather
over the next few hours.
User story 3: As a user, I want to be able to navigate backwards and forwards in
time using a slider, and view the weather up to 3 days into the future and past. I want
the slider to also be accompanied by a play button which will automatically move the
time slider across this time scale.
User story 4: As a user, I want to be able to bookmark specific locations so I can
easily navigate back to these locations. I want the program to retain persistent
memory of these bookmarks so that when I close and reopen the program, these
bookmarks are not deleted. The map layout and settings should also be saved in a
similar way such that the previous map layout is loaded back immediately, and I can
continue browsing (if I close the app).
User story 5: As a user, I want to freely switch between multiple weather overlays
(such as temperature, cloud cover, and air pressure) on the map and toggle the base
map.
User story 6: As a user, I want to search the location I want to check the weather condition 
of that location by using a search bar, And the map will automatically switch to the location 
after I clicked the result location.(JunXi Huang)
